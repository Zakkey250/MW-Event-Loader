# MW Cutscene Converter 1.0.0

Carbon／Underground 2の通常レース開始演出を、MW Event Loader用にローカル変換するWindowsアプリです。元ゲームの言語やEXEに依存しません。片方のゲームだけでも使えます。

## 必要なもの

- Windows 10／11の64bit環境。本アプリは64bitですが、出力先のMWは対応する32bit版です。
- 対応するCarbonまたはUnderground 2の資源ファイル。
- 演出の再生には対応するMW Event Loader。
- 出力ドライブは、作業後も50GiB以上の空きが必要です。

Pythonや音声デコーダーを自分でインストールする必要はありません。アプリ全体を展開し、EXEだけを取り出さずに使ってください。初回変換時に必要な読み取りライブラリの取得元・用途・保存先を表示し、承認後に自動導入します。ログインや更新チェックはありません。

初回導入時のみインターネット接続が必要です。公式GitHubとMicrosoftから固定版を最大約300MB取得し、チェックサム確認後にローカルで構築します。一時領域は最大3GBです。ライブラリと構築に使う.NET SDKは`%LOCALAPPDATA%/MWCutsceneConverter/dependencies/`内で扱い、管理者権限やシステム設定の変更は不要です。導入完了後はオフラインで使用できます。承認しない場合もアプリを開いてファイル検査できますが、変換は行いません。

## 使い方

1. アプリをゲーム外のフォルダーへ展開し、`MWCutsceneConverter.exe`を起動します。
2. 言語欄で表示言語を選びます。23言語に対応し、「システム設定に合わせる」も選べます。選択は次回も保持されます。表示言語は元ゲームの検査結果に影響しません。
3. `NIS`と`GLOBAL`があるCarbon／UG2のフォルダーを指定します。両方を指定しても、一方だけでも構いません。
4. 元ゲームとは別の出力先を選び、「ファイルを検査」を押します。利用できるシーンと台数を確認します。
5. シーンを選択し「選択シーンを変換」を押します。元ゲームのファイルは書き換えません。同一の既存出力は再利用し、内容が異なる場合は上書きせず知らせます。
6. 必要なら「導入ZIPを作成」を押します。マニフェストに記録された検査済みの再生用ファイルだけが入ります。
7. ゲームとランチャーを終了し、出力の` scripts/EventLoader/CustomCutscenes/ `をゲーム内の同じ場所へ統合します。ZIPから導入する場合も、中の`scripts`をゲームフォルダーへコピーします。
8. エディタでゲーム構成を更新し、参加台数に合うシーンか自動抽選を選びます。ゲーム内で開始・GO・スキップ・リトライを確認してください。

抽出元を変更すると、以前のシーン選択は解除されます。再度ファイルを検査してください。「シーン終了後に中止」は現在のシーンの処理後に停止し、完了済みの出力を残します。処理中に閉じた場合も、安全に片付けてから終了します。

## 変換される内容

Carbon 8シーン、UG2 22シーンに対応します。対象は通常のレース開始演出で、ストーリー専用演出は対象外です。人物、持ち物、車列、カメラ、開始合図に加え、対応する群衆、松明、発煙筒を変換します。原作の照明や粒子を完全に再現するものではありません。

空ぶかしはグリッドに実際に読み込まれた車両のエンジン音を使います。UG2の車両番号・時刻命令がある場合はそれに従い、命令がない場合は時差付きのパターンを使います。回転の変化はMW向けの近似です。追加のエンジンWAVは不要です。

### 元ゲームの入力

Carbonは対応する`NIS/Scene_*_BundleB.bun`と`GLOBAL/InGameB.bun`を使います。松明付きシーンには`attributes.bin`、`gameplay.bin`、粒子テクスチャのBUNも必要です。

UG2は対応する`NIS/Scene_IntroNis*_BundleB.bun`と、カメラの入った`GLOBAL/InGameRace.bun`等を使います。発煙筒は`GLOBAL/GLOBALB.BUN`と`GLOBAL/InGameCommon.bun`も使います。

ファイル名の大文字・小文字を区別しません。必要なフォルダー構成を保った資源ファイルだけの入力も使えます。ゲームEXE、レジストリ、インストール先の名前、特定言語のファイルを要求しません。不足・未対応ファイルがある場合は、該当するゲームやシーンに問題を表示し、利用できる他のシーンの検査を続けます。

## 音声

通常は、シーン名と一致する音声を自動検出します。手動で音源を指定したい場合は、先に出力先を選び、シーンを1つ選択して「音声を割り当て」を押します。WAVか原作音声バンクを選び、バンクの場合は1から始まるサブソング番号を指定します。割当は出力先へ自動保存されます。JSONファイルを自分で作成・選択する必要はありません。

シーン名と一致するWAVが、`NIS/<シーン名>.wav`、`NIS/Scene_<シーン名>.wav`、`SOUND/NIS/<シーン名>.wav`のいずれかに1つだけあれば、自動で使います。対応が曖昧な場合は手動指定が必要です。会話や無関係の音を言語別に推測して代用しません。

WAV入力は16bit PCM、モノ／ステレオ、8～96kHz、60秒以内です。原作バンクは同梱デコーダーで読み出します。変換結果は1シーンにつき1つのPCMトラックになり、時間・音量・長さを検査します。固定SFXを特定できない場合は、その旨をレポートに記録します。シーン全体の変換が失敗したわけではありません。

## 出力と更新

```
出力先/
  scripts/EventLoader/CustomCutscenes/<シーンID>/  ゲームへコピーするファイル
  manifests/<シーンID>.json                     出力の検査記録
  conversion-report.json                       各シーンの結果
  MW-Cutscenes-Local.zip                        作成した場合の導入ZIP
```

古い版のシーンへ部分上書きすると、不要になった粒子や音が残る場合があります。ゲーム内の既存シーンフォルダーをゲーム外へ退避してから、新しいシーン一式を置いてください。出力内容の異なるシーンを作り直す場合は、新しい出力フォルダーを使います。

## コマンドライン

```
MWCutsceneConverterCLI.exe --version
MWCutsceneConverterCLI.exe --install-dependencies --accept-downloads
MWCutsceneConverterCLI.exe --language ja --carbon "C:\Games\Carbon" --list
MWCutsceneConverterCLI.exe --ug2 "C:\Games\Underground 2" --output "D:\ConvertedScenes" --zip
MWCutsceneConverterCLI.exe --carbon "C:\Games\Carbon" --output "D:\Scenes" --scene INTRO05NG02 --zip
```

`--scene`は複数回指定できます。`--audio-map`で音声対応表を指定できます。`--language`（別名`--lang`）は画面・操作結果の言語で、入力元の言語指定ではありません。`--list`のJSONは言語によって項目名を変更しません。成功0、変換失敗1、引数エラー2で終了します。技術的なファイル解析エラーの詳細は英語の場合があります。

## データと権利

アプリに元ゲームや変換済みシーンは含みません。生成したシーンと導入ZIPは自分のゲームで使うためのものです。ゲーム由来の変換済みカットシーン、人物、テクスチャ、アニメーション、音声を公開・再配布しないでください。第三者ソフトウェアに関する情報は`THIRD_PARTY_NOTICES.md`と`licenses`を参照してください。

元ゲームを入力にして、変換成功とゲーム内の再生確認は別です。参加台数・必要ファイルを確認し、イベントの開始・終了を試してください。
