# MW Event Loader 1.2.1

## English

- Event Editor web-576 adds **Outside world map** for courses in detached areas. The event preview and radar show the course lines and markers on a transparent background.
- **Return to safehouse after the event** is a separate event option. Export the event again after enabling either option.
- Drift races can use compatible Carbon, Underground 2 and custom intro cutscenes with moving cars when the actual race starts from a standstill. Rolling race starts remain unavailable in Drift.
- The runtime ZIP includes Event Loader, ArmsAssist and HUD Lifecycle Fix, along with the RPD intro and presentation assets from 1.2.0. NFRR 0.1.4 (with Limit Breaker) and Arcade Drift Core 0.2.1 are separate downloads. Weapon modes require MWArsenal and its assets.
- When updating, keep your existing INIs, profiles, events and locally converted cutscenes.

## 日本語

- エディタ web-576 の「ワールドマップ外」を有効にすると、離れたエリアのコースを、線とマーカーだけのプレビュー・レーダーマップ付きで書き出せます。
- 「終了後にセーフハウス」をイベントごとに設定できます。いずれかの設定を変更したイベントは、エディタから再度書き出してください。
- ドリフトレースで、開始演出中に車が動くCarbon・Underground 2・自作カットシーンも、レースが静止スタートするものは選択できます。ドリフトでのランニングスタートは引き続き使用できません。
- 配布ZIPにはEvent Loader、ArmsAssist、HUD Lifecycle Fixと、1.2.0のRPD開始演出・演出資源を同梱しています。NFRR 0.1.4（Limit Breaker同梱）とArcade Drift Core 0.2.1は別途入手してください。武器種目にはMWArsenal本体とアセットが必要です。
- 更新時は既存のINI、プロファイル、イベント、変換済みカットシーンを保持してください。
